# Add2NumEx

A small, visual addition practice app for elementary school learners. Add2NumEx shows vertical addition, moves through the columns from ones to the left, and makes carrying visible.

## Setup

Prerequisites:

- Node.js 20 or newer
- npm

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

Create a production build with:

```bash
npm run build
npm run preview
```

## How to use

Enter two whole numbers and choose **Calculate**. You can also choose one of the sample problems (`24 + 17`, `58 + 26`, or `137 + 245`). The result view displays the numbers in aligned columns and explains each addition from right to left, including carried values.

## API integration

The frontend sends a `POST` request to:

```text
http://192.168.1.60:8080/api/v1/additions
```

The request body is:

```json
{
	"a": 123,
	"b": 456
}
```

The integration accepts these response formats:

```json
{ "sum": 579 }
```

```json
{ "result": 579 }
```

```json
{ "data": { "sum": 579 } }
```

Network failures, unsuccessful HTTP responses, and unreadable answers are shown as friendly in-page messages. The local step explanation is generated by `src/services/addition.ts`, while the API supplies the authoritative total.

## Project structure

```text
src/
	components/       Reusable form, result, column, step, and error UI
	services/         Addition explanation logic and API client
	App.tsx           Main screen and interaction state
	types.ts          Shared calculation types
	styles.css        Responsive classroom-inspired visual system
```

This structure leaves room for additional exercises and math operations without coupling the visual components to the API response shape.
