# Frontend Specification

## Purpose

Add2NumEx is a visual addition practice app for elementary school learners. It accepts two non-negative whole numbers, requests the authoritative total from the backend, and explains column addition from ones to the left.

## User flow

1. The learner enters two whole numbers.
2. The learner may select a sample problem.
3. The learner submits the calculation.
4. The frontend validates the input before making a request.
5. While waiting, the form shows a loading state.
6. On success, the result panel shows the total and column-by-column steps.
7. On failure, the page shows a friendly error message without exposing technical details.
8. The learner can start another calculation.

## Input rules

- Both values are required.
- Values must contain digits only.
- Values must be safe JavaScript integers.
- Negative numbers, decimals, empty values, and unsafe integers are rejected.

## UI requirements

- Provide clear labels for both number inputs.
- Keep the calculate action available from the form.
- Provide sample values for quick exploration.
- Support English and Vietnamese display text.
- Make loading, success, empty, and error states distinguishable.
- Keep the calculation explanation aligned by place value.

## Calculation behavior

- Process columns from ones to the highest input digit.
- Include the carry-in and carry-out for each column.
- Add a final carry step when required.
- The backend total is authoritative for the displayed result.
- Local step explanations are generated by `src/services/addition.ts`.

## Out of scope

- Authentication screens.
- User accounts or progress persistence.
- Additional arithmetic operations.
- Changes to backend calculation rules.
- New UI framework or state-management library.
